# 宿主机节点持有项目与终端会话

状态：已实施（2026-11-13）。用户确认：workspace 指项目；保留项目，旧 terminal 不要求迁移；支持客户端升级连接的 Falcon 服务。

## 数据归属

每个系统用户、每个 Falcon 数据目录对应一个节点，身份沿用该数据库的 `instance_id`。宿主机 B 的项目和新终端会话只由 B 的数据库及会话引擎维护。A、C 上的 Falcon 可以同时作为本机节点和访问 B 的网关，客户端仍使用既有 REST 与 WebSocket 接口。

节点间通过现有 SSH 连接转发到目标节点的回环 HTTP 端口。B 不需要开放公网接口。首次部署由入口下载适合 B 的官方服务端产物，校验后推送并运行。已有同数据目录的兼容节点直接复用，不因连接方版本更新而自动替换。

窗口列、画布和选中项是客户端本地状态，继续分别保存。SSH 凭据留在连接发起方，不随项目迁移到 B。

## 资源与转发

网关向客户端返回的远端项目、会话 ID 为 `node:<节点ID>:<base64url资源ID>`。同一个节点通过不同地址连接时仍返回相同资源身份。`standalone:local` 在网关侧映射到当前连接配置的 `standalone:host:<id>`。

项目与会话的写请求、文件和 Git 请求根据资源身份转发到所属节点；终端 WebSocket 在 SSH 通道上转发消息边界，二进制终端输出保持原样。实际会话生命周期、终端尺寸与外观的多观看端仲裁集中在 B 的会话引擎。关闭 A 或断开 A 的 SSH 不终止 B 的持久会话。

节点内部列表请求带宿主机上可读取的节点令牌，只返回本地资源，避免 A 与 B 互连时递归聚合。网关缓存列表并在连接失败时保留最后结果；会话标为待接回，节点接口报告连接错误。首次连接与部署在后台完成，列表不会等待完整部署过程。

创建项目、终端和附属项目的请求携带 `Idempotency-Key`。节点先持久记录请求指纹再执行：相同请求重放已完成的响应；同一标识不同内容返回冲突。执行中进程退出而结果尚未记录时，后续请求明确返回结果未确认，要求刷新资源列表，不重新执行副作用。

## 项目迁移

`host-projects.json` 退出日常双向同步，只作为首次迁移输入。宿主机节点启动时以 SQLite Backup API 备份并导入清单；网关第一次连接时导出自己保留的该宿主机旧项目属性，凭 SSH 可读的节点令牌请求 B 导入。普通项目编辑接口不能写入迁移的 worktree 所有权字段。

迁移保持项目目录不变，保留源项目、附属项目、多仓库、shell、默认派生基点和存档元数据。`remote_id` 先映射到 B 的真实主键，再恢复附属关系。相同资料可重复导入；同身份不同资料整批拒绝，保留原记录供处理。迁移不会根据目录外观推断目录可删除。

成功后记录旧 ID 到节点资源的映射；旧 SSH 项目记录仅作迁移缓存，不能再由网关的存档定时清理执行目录删除。旧终端不迁移，也不主动终止；新会话只在 B 上登记。

## 节点升级

服务端升级与桌面应用更新分别管理。桌面和 Android 使用相同的检查、发起、状态查询接口。SSH 节点的更新包允许由网关下载、验证后上传，目标节点无需访问发布站点。

升级依次执行下载/传输、SHA-256 校验、候选程序版本和平台探测、持久任务登记、备份、替换、重启和实际运行健康核对。同一节点升级单飞；客户端断开后任务继续，重连只查询结果而不重复提交。

独立更新帮手负责跨平台替换和恢复。候选程序先以维护状态完成数据库与项目迁移并响应健康核对，成功提交前不开放普通业务写入；只有该边界之前可恢复旧数据库。开放写入后不能用旧备份覆盖已接受的新写入，后续启动失败必须明确报告。持久会话由独立 sessiond 持有，节点服务重启不结束它们；非持久会话的影响在升级操作前说明。

## 验证

局部测试覆盖资源身份、请求重放、三库项目迁移、事务失败、备份、删除护栏、节点引导与升级状态。网关集成测试以隔离数据目录、真实 HTTP、PTY 和 WebSocket 验证 A 创建、C 列举并连接 B 的同一会话；真实 SSH 验证须使用隔离 HOME 的 sshd。

节点身份、节点连接状态、升级检查与任务状态的协议类型统一在 `falcon-proto`。`cargo xtask fixtures --node-updates-only` 以隔离服务端重生这四个端点的真实响应，`cargo test -p falcon-proto --test fixtures` 检查反序列化与无字段丢失。

Windows 运行行为需要 Windows 环境验证；仅有跨平台编译不能视为真机验证。具体执行结果见实施任务的最终报告。
