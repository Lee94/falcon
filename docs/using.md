# 使用

持久会话的机制与限制见 [sessions.md](./sessions.md)。

## SSH 主机

SSH 连接可以在设置里预先保存成远端主机。新建 SSH 项目时直接选择，不用每次重填主机、端口和凭据。

## 中转

端口转发与公网发布合称中转，在设置的「中转」页管理。规则按机器挂，不跟项目走：挂载点是 falcon 后端本机，或一台已保存的 SSH 主机。隧道走该主机自己的链路，没有打开的终端也可以保持。启用中的隧道在链路断开后会跟着重连。同一端口可以存多条，同时只有一条生效。见 [ADR 0016](./adr/0016-relays-by-host.md)。

端口转发挂在 SSH 主机上。本地转发把远端能到达的地址映射到后端本机的端口；远端转发把后端能到达的地址暴露给远端。本机没有端口转发。

公网发布把一台机器上的 HTTP 服务经 Cloudflare Quick Tunnel 发到公网，得到一条临时的 `*.trycloudflare.com` 地址，不需要 Cloudflare 账号。挂本机就直接打本机端口；挂 SSH 主机就先经该主机的链路接到后端，再由本机的 `cloudflared` 发出去。`cloudflared` 只在 falcon 后端本机跑，第一次发布时按锁定版本下载到数据目录的 `bin/`。地址随进程重启而变，不写入数据库。任何拿到链接的人都能访问。v1 只代理 HTTP。见 [ADR 0014](./adr/0014-cloudflared-public-share.md)。

## 粘贴图片

终端里可以直接粘贴截图或拖入图片文件，SSH 远端的会话也包括在内。图片写到会话宿主机的 `<falcon 根>/paste/`（远端为 `~/.falcon/paste/`），终端输入框里出现的是落盘路径。Claude Code 等 TUI 认输入框里的图片路径，效果等同把文件拖进原生终端。剪贴板同时有文本和位图时贴文本。旧图 24 小时后自动清理。

## 打开终端里的路径

原生客户端可以打开终端输出中的文件路径：macOS 上按住 ⌘ 点击，Windows 与 Linux 上按住 Ctrl 点击，在文件查看窗口中打开会话宿主机上的文件。图片路径无需按键，悬停两秒后显示缩略预览，移开即关闭。

支持绝对路径、相对路径、`~/`、`file://`、带行列后缀的诊断路径与软折行。带空格的路径需用引号或反引号包围。相对路径优先使用 shell 经 OSC 7 上报的当前目录，未上报时以项目工作目录为基准。

## 右侧栏

文件与修改是内置面板。其后可以挂插件：内置的系统监控、Docker、Agent 用量，以及放进数据目录的命令插件，都走同一套面板文档。作者手册见 [plugins.md](./plugins.md)，决定见 [ADR 0025](./adr/0025-right-panel-plugins.md)。

项目菜单里的「用 px0 审阅」在项目宿主机上拉起 px0，经 falcon 同源反代打开。SSH 项目的 px0 跑在远端。见 [ADR 0017](./adr/0017-px0-review.md)。

## 附属项目（git worktree）

项目工作目录在一个 git 仓库里时，项目菜单会多出「派生附属项目…」：选一条分支（新建或检出已有），falcon 跑一次 `git worktree add`，在仓库根的同级建出目录并落一条新项目。

```
D:\code\
├── falcon\            ← 源项目
├── falcon-feat-x\     ← 附属项目（分支 feat/x）
└── falcon-hotfix\     ← 附属项目（分支 hotfix）
```

单仓库的附属项目在侧栏缩进显示在源项目下面，有自己的名字、自己的会话、自己的生命周期，与源项目共用同一台宿主机和同一份连接配置。SSH 项目也能派生，命令在远端跑。多仓库项目的批量派生直接新增一个同级的多仓库项目，不缩进在源项目下面，见 [ADR 0003](./adr/0003-multi-repo-projects.md)。术语见 [CONTEXT.md](../CONTEXT.md)。

删除附属项目会连目录一起删。这是 falcon 唯一会删除用户目录的地方：

- 删除前会读一次工作区状态，把未提交的改动，以及被 `.gitignore` 忽略的文件（`.env`、本地数据库这些通常只有一份）摆在确认框里。读不到状态就写明「无法确认」，不当成是干净的。
- 动手前要同时满足一串断言：路径是 falcon 自己记下的、目录确实是 falcon 建的、不是仓库根 / 家目录 / 盘符根、深度足够、没踩到别的项目的工作目录，且它此刻仍然是那个仓库的 worktree（主仓库丢失时退而检查 worktree 独有的 `.git` 文件）。任何一条不成立就不删，并把路径告诉你。
- 被 `git worktree lock` 锁住的 worktree 一律不碰，也不自动解锁。
- 分支永远保留。`git worktree prune` 只在走了兜底删除时才跑。
- 删源项目会级联删掉它的全部附属项目（确认框逐条列出路径），源项目自己的目录不动。那个目录不是 falcon 建的。

删除护栏的决定见 [ADR 0002](./adr/0002-worktree-derived-projects.md)。
